# 수업의 서랍

선생님이 직접 도구를 등록하는 교육용 허브와 모둠 자리배치 앱입니다. 기존 윤리 게임과 분리된 프로젝트입니다. 명세의 단순 대안인 HTML/CSS/JavaScript 모듈을 사용하며 의존성 설치가 필요 없습니다.

## 실행

Windows에서 START.cmd를 실행하거나, 이 폴더에서 `node server.cjs`를 실행하고 http://127.0.0.1:4320 에 접속하세요. START.cmd는 PATH의 Node.js를 먼저 찾고, 없으면 이 PC의 Codex 내장 Node.js를 찾습니다. 다른 PC에는 Node.js가 필요할 수 있습니다. npm을 사용할 수 있다면 `npm start`도 가능합니다. index.html을 직접 더블클릭하지 말고 로컬 서버로 실행하세요. 서버는 이 앱 파일만 제공합니다. 포트가 이미 사용 중이면 기존에 실행한 주소로 접속하거나 기존 서버를 종료한 뒤 다시 실행하세요.

## 사용

1. 허브에서 도구 이름·설명·웹 주소를 등록합니다. 도구 목록만 현재 브라우저에 저장합니다.
2. 모둠 자리배치를 열고 선택과목반 이름을 입력합니다.
3. 모둠별 이름 붙여넣기 또는 전체 이름 입력을 선택합니다. 전체 입력 시 모둠을 추가한 뒤 학생 옆 메뉴에서 직접 배정합니다. 한 모둠에 최대 6명입니다.
4. 교실 자리배치에서 줄·칸 정렬 후 모둠 이름 부분을 끌거나 이동 버튼으로 조정합니다. 같은 모둠 안에서 두 자리를 선택하면 이름이 교환됩니다.
5. 위치만·개인 자리만·둘 다를 선택해 무작위 재배치합니다. 모둠 구성원은 유지됩니다.
6. 파일로 저장한 뒤 교실 PC의 같은 앱에서 불러옵니다. 한 JSON 파일에 한 반을 담습니다. 반 이름을 입력해야 저장할 수 있습니다.
7. 수업 화면을 열어 전체화면으로 표시하고, 종료 시 명단 닫기를 누릅니다.

시제품은 ‘가상 명단으로 둘러보기’로 확인할 수 있습니다. 학생 자료를 서버에 보내거나 브라우저 저장소에 보관하지 않습니다. 새로고침하면 편집 명단이 사라지므로 파일 저장을 확인하세요. 다운로드 요청은 실제 저장 완료를 보증하지 않습니다. 명단을 닫아도 디스크 파일·백업·다운로드 기록은 남습니다. 파일은 교사가 직접 관리하세요. 실제 이름 사용과 파일 보관·프로젝터 표시는 학교 기준을 확인하세요.

## 검증

`npm run check` — JavaScript 구문 검사

`npm test` — 파일 왕복·잘못된 파일·모둠 인원 제한·재배치 범위·위치 겹침·URL 검증

수동 점검: 허브 새로고침, 두 명단 입력, 학생 이동과 자리 교환, 파일 다운로드·불러오기, 키보드 이동 메뉴, 전체화면 종료와 명단 닫기. 실제 교실 프로젝터 가독성과 학교 PC 브라우저 호환은 현장에서 확인하세요. 큰 반은 화면 크기에 맞춰 줄·칸을 조절해야 합니다. 학생 정보를 도구 설명이나 외부 주소에 넣지 마세요.

서버·로그인·클라우드 동기화·인쇄·자동 모둠 편성·완전 오프라인 재실행은 포함하지 않습니다. 허브 목록은 다른 PC로 자동 복사되지 않지만 자리배치 도구는 기본 제공됩니다. 공개 배포는 실행하지 않았습니다.

## PDF 글자 수 도구

허브에 기본 제공됩니다. 기존 브라우저의 도구 목록에도 자동으로 추가됩니다.
- PDF 선택 또는 끌어놓기(100MB 이하), 공백 포함/제외 전체·페이지별 집계, 추출 텍스트 확인.
- PDF.js 4.10.38 및 CMap·기본 폰트를 vendor에 포함했습니다. CDN이나 외부 API를 사용하지 않습니다. 출처: https://github.com/mozilla/pdf.js (Apache-2.0, vendor/LICENSE).
- 파일은 File.arrayBuffer로 브라우저 메모리에 읽습니다. 파일/결과는 localStorage·IndexedDB·서버에 저장하지 않습니다. 새로고침/지우기로 결과를 제거합니다.
- 서버는 127.0.0.1에서만 수신하고 GET/HEAD만 허용합니다. CSP는 외부 연결을 차단하며 PDF.js 리소스는 같은 로컬 서버에서만 읽습니다.
- 스캔 이미지 OCR 미지원. 암호 PDF는 해제한 사본이 필요합니다. 줄바꿈은 제외하며 Unicode 코드 포인트를 셉니다. 문서 구조에 따라 띄어쓰기·읽기 순서에 차이가 있을 수 있습니다.
- 서버를 이미 실행 중이었다면 Ctrl+C로 종료한 후 START.cmd로 다시 실행하세요.
- node --test tests/*.test.mjs: 총 11개 통과(실제 PDF 바이트 추출 포함). 브라우저 미리보기는 로컬 연결 시간 초과로 확인하지 못했습니다.

## 계약의 숲 연결
기본 도구함에 홉스·로크·루소 사회계약론 미로 게임을 추가했습니다. 기존에 저장한 도구 목록을 유지하며 자동으로 추가되고, 같은 게임 주소가 이미 있으면 중복 등록하지 않습니다. 도구 열기를 누르면 배포된 게임이 새 탭으로 열립니다. 게임은 현재 소유자 비공개이며 학생 공유 전에는 별도로 접근 범위를 변경해야 합니다.

## 하루의 조각 · 로컬 일기장

허브의 일기장 카드 또는 http://127.0.0.1:4320/diary/ 에서 실행합니다. 날짜별 한 편을 작성하고 제목·내용·기분을 저장합니다. 기존 기록 수정·삭제, 제목/내용 검색, 월별 필터를 지원합니다. 저장 버튼을 눌러야 디스크에 기록됩니다.

데이터베이스는 이 프로젝트의 `data/diary.sqlite`입니다. 서버 재실행과 브라우저 기록 삭제 후에도 유지됩니다. SQLite WAL 모드이므로 백업할 때는 서버를 종료한 뒤 `data` 폴더 전체를 복사하세요. 데이터 폴더는 Git에서 제외하며 HTTP로 제공하지 않습니다. 이 PC의 폴더를 사용하는 로컬 앱이며 클라우드에 배포하지 않습니다. 별도 로그인이나 데이터베이스 암호화는 없습니다.

Node.js 22.13 이상(Node 24 권장)이 필요합니다. START.cmd로 실행하세요. 서버는 127.0.0.1에서만 수신합니다. 일기 저장·삭제 API는 JSON과 동일 출처 요청만 허용합니다. 모둠 자리배치/PDF 데이터 저장 방식은 기존과 같습니다.

검증: 기존 테스트와 일기 DB 재연결 복원·수정 충돌·삭제·날짜 검증·허브 자동 연결 테스트 13개 통과.

## 공개 소스

이 저장소에는 실행 코드와 테스트만 포함하며 실제 일기·학생 명단·PDF는 포함하지 않습니다. Node.js 22.13 이상이 필요합니다. 보안 및 운영 범위는 SECURITY.md를 확인하세요. GitHub Pages 및 인터넷 서버 배포는 구성하지 않았습니다.
