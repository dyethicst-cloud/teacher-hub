파일 선택은 업로드가 아닙니다. 외부 서버 전송·분석·자동 저장 없이 브라우저 메모리에서 처리합니다. 새로고침하거나 지우기를 누르면 결과가 사라집니다. 인터넷 연결 없이도 로컬 서버에서 사용할 수 있어요.

집계 기준: 유니코드 코드 포인트 기준이며 줄바꿈과 페이지 구분은 제외합니다. 공백 제외는 띄어쓰기·탭 등 모든 공백을 뺍니다. PDF의 텍스트 저장 방식에 따라 띄어쓰기나 읽기 순서가 원문과 다를 수 있어요. 이미지 속 글자와 주석·입력 양식의 글자는 집계하지 않습니다.
